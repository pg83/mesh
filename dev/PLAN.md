**Principle: no handshake.** Mesh is designed to avoid handshakes: the first packet already carries data, the channel is determined by packet contents rather than state, and restarts and NAT do not break it. A handshake over UDP reinvents TCP, which we avoid at all costs. This constrains the mechanism, not the properties: forward secrecy, key rotation, and other features must use schemes with no exchange before data (ephemeral keys and epochs travel inside ordinary packets, old keys expire and are erased, and so on).

**Forward secrecy and rekeying.** Each pair of nodes shares one static secret for the lifetime of their keys. If a node's key leaks, all of its past traffic with every peer can be decrypted. Implement this without a handshake: carry the ephemeral public key in ordinary packets; each side switches to a key derived from ephemeral DH as soon as it sees the peer's ephemeral key, and uses the static key pair until then. A header byte selects the epoch, and old keys are erased after a timeout. The first packet still carries data; there is no state before data.

**RTT.** One-way gossip cannot measure it; ping/pong is needed as another inner packet type. This also introduces a second selection criterion: avoid flapping links.
